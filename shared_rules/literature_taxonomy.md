# literature_taxonomy.md

## 文件定位

本文件规定社会科学研究项目中的文献功能分类、文献矩阵最小字段和文献综述组织原则。它只保留跨项目稳定规则。

具体检索步骤、矩阵生成、snowballing 执行和 synthesis memo 写法，应进入 `workflows/literature_mapping.md`、`skills/literature-map-builder/` 和 `skills/citation-snowballing/`。

## 基本原则

文献整理服务论文生产，不服务资料堆积。AI 不应只回答“有哪些相关文献”，还应判断每篇文献可能在论文中承担什么功能。

本地文献库通常只能访问标题和摘要，不一定能访问全文。因此，基于本地文献库的判断只能定位为：

- 定位文献；
- 判断潜在相关性；
- 梳理可能的文献脉络；
- 生成阅读优先级。

不要把摘要层级判断写成已经阅读全文后的确定结论。凡是需要全文确认的机制、模型、变量、稳健性或结论，都应标记为需要进一步阅读。

文献相关性不能只由主题相似度决定。研究对象相似的文献可能只适合作为背景；研究对象不同的文献可能提供关键概念；结论不一致的文献可能帮助识别竞争解释。

## 功能分类

默认使用以下分类：

| 标签 | 用途 |
| --- | --- |
| `core_conversation` | 本文最可能直接回应的文献，通常共享研究问题、因变量、理论争论、经验对象或核心机制。 |
| `theoretical_anchor` | 提供核心概念、机制或解释框架，但未必研究相同数据、国家、群体或结果变量。 |
| `empirical_precedent` | 提供相似数据、样本、地区、研究设计、测量方式或经验发现。 |
| `institutional_background` | 提供宏观趋势、社会制度、人口变化、政策背景、文化语境或国家/地区特征。 |
| `competing_explanation` | 提供替代理论、反向证据、不同解释路径或审稿人可能提出的质疑。 |
| `uncertain` | 标题或摘要不足以判断功能，不是低相关，而是需要更多信息。 |

测量、变量构造和方法选择不作为默认独立大类。若一篇文献主要在这些方面有用，应在 `project_relevance` 或 `notes` 中说明。

## 文献矩阵字段

文献矩阵应简洁、可维护。建议字段：

```text
citation_key
authors_year
title
journal
year
abstract
literature_role
relevance_level
project_relevance
paper_section
must_read_full_text
notes
```

字段使用原则：

- `literature_role` 使用上面的功能分类。
- `relevance_level` 使用 `high`、`medium`、`low` 或 `uncertain`。
- `project_relevance` 是最重要字段，说明该文献与当前项目的关系。
- `paper_section` 说明可能进入 introduction、literature review、theory、data and methods、results、discussion 或 appendix。
- `must_read_full_text` 标记是否需要进一步阅读全文。
- `notes` 记录不确定性、后续检查事项或补充判断。

不建议在摘要检索阶段设置过多细碎字段，例如因变量、核心自变量、机制、样本、模型、数据方法等。如果这些信息摘要中清楚出现，可以合并写入 `project_relevance` 或 `notes`；如果摘要没有出现，不应强行填充。

## 核心文献识别

核心文献不等于所有高相关文献。核心文献应满足至少一项：

- 直接处于本文要进入的学术对话；
- 提出本文必须回应的理论或经验命题；
- 在领域内经典或近期重要；
- 其不足或未解决问题正是本文贡献所在；
- 其方法、样本或测量方式可能直接影响本文研究设计。

标题和摘要层级只能识别候选核心文献。候选核心文献应单独标记，后续通过阅读全文、阅读引言和结论、查看引用关系等方式确认。

核心文献集合应保持克制。初步可识别 10-20 篇候选核心文献，再根据阅读和研究进展扩展。

## Snowballing 原则

参考文献追踪和被引文献追踪应围绕少量候选核心文献展开。不要对所有相关文献做 snowballing。

Snowballing 的目标是补充遗漏的重要文献，而不是增加文献数量。每篇候选文献都必须说明进入理由，例如核心理论来源、经典经验研究、关键反向证据或近期重要研究。

## 文献综述原则

文献综述不应逐篇罗列，而应按学术问题和理论脉络组织。AI 生成综述时，应优先回答：

- 已有研究解释了什么；
- 仍然缺少什么；
- 本文如何进入这个缺口；
- 哪些竞争解释需要处理。

仅依据标题和摘要生成的综述只能作为初步文献地图，不应写成最终综述文本。

应避免只按主题堆积文献、只引用支持本文的研究、把背景文献当成核心文献、缺少竞争解释、没有说明增量贡献，或基于摘要过度推断全文论证。
