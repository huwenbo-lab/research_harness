# Analysis Notes Index

## 2026-09-18 — Project initialization

Current priority is bibliography construction, not substantive narrative coding.

Pilot sequence:

1. Validate JJWXC annual catalog retrieval for 2010, 2015, 2020, 2025.
2. Validate Qidian catalog recovery for comparable publication cohorts or identify a defensible historical substitute.
3. Parse saved catalog pages into `source_observation` format.
4. Run `audit_catalog.py` and inspect ID/date/missingness patterns.
5. Only then expand to 2010–2025 annual coverage.
6. After the sampling frame is stable, link synopsis/opening/full-text sources and design the gold-standard coding sample.

Open methodological questions:

- exact meaning and stability of each platform's displayed publication date;
- survivorship of older/deleted works in current catalogs;
- handling reposts, renamed works, and cross-platform migration;
- whether 2005–2009 can meet the same comparability standard as 2010 onward;
- whether Qidian and JJWXC should be modeled separately first and only compared after platform-specific trend estimates are established.
